# Oramat a Fixmat — produktové popisy

Aktuálna finálna verzia schváleného interaktívneho atlasu10 s navigáciou1 je v [galérii finálnych popisov](https://djubek.github.io/oramat-fixmat-navrhy/final/). Obsahuje WKCP a HOX v slovenčine aj češtine, vrátane všetkých parametrov, výkresov, výhod, použitia, montáže, médií a FAQ. Prepína produkt, obchod a mobilný alebo desktopový pohľad.

V koreňovej galérii zostáva historické porovnanie40 návrhov. Staršie experimenty nepredstavujú aktuálny produkčný štandard. Obsah a samostatné odkazy fungujú aj bez JavaScriptu. Žiadne zákaznícke, prihlasovacie ani interné auditné dáta nie sú súčasťou verejného balíka.
